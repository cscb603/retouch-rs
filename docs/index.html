📖 功能一览

🎨 套色/AI追色 初色独有

导入任何一张喜欢的照片（网上大片、电影截图、大师作品），初色自动分析它的颜色特征，把你的照片调成同样的色调。PS/LR 都没有这个功能。

🧠 感知色彩引擎 核心技术

所有算法在 OKLab 感知色彩空间里运行。调亮度、加对比、提饱和——增减时人眼觉得自然舒适，不会像 PS 线性工具那样拉出刺眼的塑料感、把阴影高光细节毁掉。

⚡ 曝光 / 影调

感知曝光（非线性，符合人眼）、AgX/Filmic 电影映射曲线、SoftKnee 胶片曲线（暗部不死黑、高光不死白）、光比融合、去雾。

🌡️ 白平衡

色温（冷↔暖）和色调（绿↔品红）。配合「自动白平衡」一键搞定。也支持「参考图色温匹配」。

🔍 HSL 分区调色

8 种颜色各自独立调。天空不够蓝 → 蓝色组加饱和、降明度。草地太黄 → 绿色组调色相。不会连带影响其他颜色。

🧏 人像美肤

一键美肤 + 粉嫩肤色（去黄/提亮/加红/加粉）+ 频谱磨皮（频率分离技术，保留毛孔细节去斑，比普通磨皮更自然）。

🎞️ 胶片预设

6 种风格：中性胶片·暖/冷、富士色调、Portra 人像、Kodak Gold、莫兰迪·低调。点一下就有故事感。

🤖 智能辅助

一键中性化（分析直方图+色偏，纯算法校正）、自动曝光、自动白平衡、智能去雾、全智能（三合一）。

📐 几何校正

旋转、透视校正、翻转、裁剪（1:1/3:2/4:3/16:9 一键预设）。

📤 导出 & 相册

导出尺寸：原图 / 1080px 朋友圈 / 2048px 高清 / 3000px 印刷。白边边框 / 宝丽来相框可选。相册最多 50 张，参数独立记忆，批量导出。

📲 安装

⚠️ Mac 用户第一次打开是这样的：
你可能会看到提示说「无法验证开发者」或「已损坏，移到废纸篓」。
这不是软件坏了，也不是病毒。只是因为 Mac 系统对非 App Store 下载的软件有安全限制，需要手动放行一次。按下面的步骤做就好。
1

把 初色.app 拖到「应用程序」文件夹

2

不要双击——请右键点击 → 选择「打开」→ 弹窗里选「打开」

3

之后就能像普通软件一样双击打开了。弹窗要求「输入密码」是系统在问电脑的管理员密码（不是初色要你钱），正常输入就行。

💡 如果不小心点了「移到废纸篓」：
去废纸篓把它找回来恢复。然后右键 → 打开 → 选打开。没坏，放心。

💡 Windows 用户：
正常双击安装就能用，没有任何额外步骤。
