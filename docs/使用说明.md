# 初色 · 轻量修图工具

> 30MB，免费，纯本地算法，不联网、不占空间、照片不传出设备

## 跟 PS 有什么不一样？

| | 初色 | Photoshop |
|---|---|---|
| 体积 | **30MB** | 4GB+ |
| 价格 | **免费** | ¥3xxx/年 |
| 启动 | **瞬间** | 等半分钟 |
| 联网 | **不需要** | 需要 |
| 隐私 | **不上传照片** | 不一定 |

初色不是要取代 PS，而是：**日常修图 90% 的需求，一个 App 就够了。**

曝光白平衡、HSL调色、去雾通透、污点修复、肤色美颜、胶片风格、裁剪旋转、批量导出——Lightroom 和 Camera Raw 里常用的功能都有，算法甚至更聪明（OKLab 感知色彩空间、Poisson 无缝克隆）。

## 安装

1. 收到 `初色.app` 后拖到「应用程序」文件夹
2. **不要双击！** 右键 → 选择「打开」
3. 弹出的提示框，选「打开」
4. 之后就可以正常双击打开了

> ⚠️ 因为是独立开发者免费分享，没有 Apple 签名证书，macOS 会提示「无法验证开发者」。这不是病毒，放心继续。

## 快速入门

1. 拖一张照片到窗口，或点「打开」（Cmd+O）
2. 左边调参数——曝光、色温、饱和度、HSL……拖一拖看效果
3. 试试「一键中性」——3秒自动校正
4. 点「污点」→ 涂掉多余的东西 → 松手自动愈合
5. 点「保存」（Cmd+S）→ 选尺寸 → 出图

## 核心功能一览

### 曝光 / 影调
曝光、影调映射（AgX/Filmic）、胶片曲线、光比融合、提亮、对比、去雾、提亮暗部、提亮黑位

### 白平衡
色温（冷暖）、色调（绿/品红）

### 色彩
饱和度、鲜艳度、色相旋转、暗部染色、高光染色

### HSL 分区（8 色相 × 3 维度）
调整某种颜色：天空不够蓝？调蓝色组。草太黄？调绿色组。

### 肤色 / 美肤
一键美肤、粉嫩肤色（去黄/减淡/加红/加粉）、频谱磨皮（PS 同款频率分离）

### 污点修复
去掉电线杆、痘痘、杂物。三种算法：传统（小污点快）/ 自然（频率分离）/ 精修（Poisson 无缝克隆，默认推荐）

### 几何 / 裁剪
旋转、透视校正、翻转、裁剪（1:1/3:2/4:3/16:9 比例预设）

### 细节
降噪、锐化、柔光

### 胶片风格
6 种预设：中性胶片·暖/冷、富士色调、Portra 人像、Kodak Gold、莫兰迪·低调

### 智能一键
自动曝光、自动白平衡、智能去雾、一键中性化（纯算法、不上传）

### 相册 / 批量
一次导入 50 张，每张独立调色，批量导出
