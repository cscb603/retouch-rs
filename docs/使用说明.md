| | 初色 | Photoshop |

## 二、下载与安装

> 每个压缩包里都带一份 `首次打开必看-初色.txt`，第一次打开被系统拦住时照着点一下即可。

### macOS（分享版 `初色-0.6.9-macOS.zip`）
1. 解压得到 `初色.app`。
2. **不要直接双击！** 在 `初色.app` 上【右键 → 打开】，弹窗里再点一次「打开」（只需一次，之后双击即可）。
3. 若弹窗只有「完成 / 删除」，去「系统设置 → 隐私与安全性 → 仍要打开」。
4. 也可拖到「应用程序」文件夹长期使用。

### Windows 10 / 11 64 位
- **分享版** `初色-0.6.9-windows-分享版.zip`：无 AI Key，双击即用，免装 VC++ 运行库。
- **自用版** `初色-0.6.9-windows-自用版.zip`：已内置 Qwen Key，AI 追色/命名可用。
1. 把文件夹解压到任意位置（桌面、D 盘均可，路径可含中文）。
2. 双击 `初色.exe`。首次会被 SmartScreen 拦：点「更多信息 → 仍要运行」即可（一次之后不再拦）。
3. 右键 `初色.exe → 属性 → 解除锁定` 也可永久放行。
4. **自用版需放好 Key**：把包里的 `qwen_key` 文件复制到 `C:\Users\你的用户名\.retouch\qwen_key`（`.retouch` 文件夹没有就新建，注意前面有个点），或在软件「设置 → Qwen Key」里粘贴其内容。放好后 AI 功能即可联网。

> 界面用了随包的开源「思源黑体」（`fonts/` 目录），**别删 fonts 文件夹**，否则中文会变成方块。

## 三、快速入门（5 步上手）

1. 拖一张照片进窗口，或点「打开」（Cmd/Ctrl+O）。
2. 左边调参数——曝光、色温、饱和度、HSL……拖一拖看效果。
3. 试试「一键中性」——几秒自动校正白平衡与影调。
4. 点「污点」→ 涂抹多余的东西（电线杆、痘痘、杂物）→ 松手自动愈合。
5. 点「保存」（Cmd/Ctrl+S）→ 选尺寸 → 出图。

支持格式：JPG / JPEG / PNG / TIFF / **WebP** / **HEIC / HEIF**（HEIC 在 Mac 上自动转码）。

## 四、核心功能一览

- **曝光 / 影调**：曝光、影调映射（AgX / Filmic）、胶片曲线、光比融合、提亮、对比、去雾、提亮暗部、提亮黑位。
- **白平衡**：色温（冷暖）、色调（绿 / 品红）。
- **色彩**：饱和度、鲜艳度、色相旋转、暗部染色、高光染色。
- **HSL 分区（8 色相 × 3 维度）**：天空不够蓝？调蓝色组。草太黄？调绿色组。
- **肤色 / 美肤**：一键美肤、粉嫩肤色（去黄 / 减淡 / 加红 / 加粉）、频谱磨皮（PS 同款频率分离）。
- **污点修复（四档）**：
  - 传统（Telea）——小污点兜底，最快；
  - 自然（频率分离）——源块高频纹理 + 目标邻域低频光照融合；
  - 精修（Poisson 梯度域无缝克隆）——完全无痕，默认档，适合小瑕疵 / 人像；
  - 内容感知（PatchMatch）——细线 / 电线 / 杆 / 细缝专用。
- **几何 / 裁剪**：旋转、透视校正、翻转、按比例裁剪（1:1 / 3:2 / 4:3 / 16:9）。
- **细节**：降噪、锐化、柔光。
- **胶片风格**：6 种预设（中性胶片·暖 / 冷、富士色调、Portra 人像、Kodak Gold、莫兰迪·低调）。
- **智能一键**：自动曝光、自动白平衡、智能去雾、一键中性化（纯算法、不上传）。
- **相册 / 批量**：一次导入数十张，每张独立调色，批量导出（MozJPEG 4:4:4 高质量）。

### 本次版本新增（商业软件标准 4 项）
1. **关闭窗口有「未保存更改」提示**——有改动时关窗弹确认框（保存并退出 / 放弃并退出 / 取消），不再悄悄丢工作。
2. **支持 WebP / HEIC**——打开与拖入都认这两种格式。
3. **一键中性化不再削弱后续手动调整**——旧版会把结果按 `mix<1` 与原图混合「防过曝」，副作用是后续拖曝光/对比被整体打折、像「调了没反应」；现改为 `mix` 恒为 1.0，过曝由内部护栏负责。
4. **自动保存 / 崩溃恢复**——每 5 秒静默写一次进度；意外退出后重开，若原图还在会问你要不要恢复。

## 六、命令行（CLI）后台调用

初色同时提供**无界面命令行引擎** `retouch-rs`，适合后台批量处理、自动化流水线、AI Agent 调用——GUI 里能做的，命令行都能跑，且不占桌面。

**获取 CLI 二进制**：用源码编译 `cargo build -p retouch-cli` 即可（Windows 分享包只含 GUI，CLI 需自行编译）。

**子命令速查**：

| 命令 | 作用 |
|---|---|
| `retouch-rs render 原图.jpg 成品.jpg --exposure 0.3 --contrast 0.15` | 跑 OKLCH 管线渲染，参数可逐个覆盖 |
| `retouch-rs analyze 原图.jpg --json` | 把图片量化成 AI 可读的 OKLCH 指标（Agent「看」图用，不传像素） |
| `retouch-rs auto 原图.jpg 成品.jpg` | 一键智能调色（本地规则 / 可选 Qwen API） |
| `retouch-rs name 原图.jpg --key <QWEN_KEY>` | 用 Qwen 给图片起名 / 评分 |
| `retouch-rs schema --json` | 导出全部可调参数 id（供 Agent 程序化设参） |
| `retouch-rs dump --preset x.toml 输出.toml` | 把 preset + CLI 参数固化成 TOML |
| `retouch-rs verify 原图.jpg` | 自检：色彩保真 / 功能正确 / 性能基准 |

**参数组合**：任意子命令都能 `--preset xxx.toml` 作底，再用 `--exposure` 等逐个覆盖；或直接 `--params '{"exposure":0.3}'` 按参数 id 设定。可用参数见 `retouch-rs schema --json`。

**后台批量示例**（无窗口，可丢服务器跑）：

```bash
# 批量把整目录照片按同一套参数渲染
for f in raw/*.jpg; do
  retouch-rs render "$f" "out/$(basename "$f")" --preset my-grade.toml --sharpen 0.4
done
```

## 七、常见问题

**Q：会被当病毒吗？**
A：免费分享版没做付费签名，系统首次会拦一下，放行一次就好，不是病毒、不会自动删。

**Q：以后每次打开都要这样吗？**
A：只在第一次。之后双击直接进。

**Q：支持什么系统？**
A：macOS 11+（Apple 芯片 / Intel 均支持）；Windows 10 / 11 的 64 位。

**Q：AI 功能要钱吗？**
A：AI 追色 / 命名用的是你自己的 Qwen Key（自用版已带，或在软件里填），费用按 Qwen 官方计费，软件本身免费。

**Q：照片安全吗？**
A：常规修图全部本地完成，照片不出电脑；仅 AI 功能会把缩略图发给 Qwen 接口做识别。
